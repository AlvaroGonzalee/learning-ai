# Fase 1 - Python y matematicas base

Objetivo de esta fase: construir intuicion matematica programando piezas pequenas desde cero.

Duracion sugerida: 3 a 4 semanas.

## Como empezar

1. Completa los ejercicios en orden. El enunciado y las explicaciones estan al principio de cada archivo.
2. Ejecuta el ejercicio:

```bash
python3 ejercicios/01_vectores.py
python3 ejercicios/02_matrices.py
python3 ejercicios/03_funciones_y_derivadas.py
```

3. Modifica el archivo y vuelve a ejecutarlo.

## Meta de la fase

Crear una mini libreria matematica para IA con:

- Vectores
- Matrices
- Derivadas numericas
- Funciones de activacion

No busques memorizar todo. Busca entender que representan las operaciones y por que se usan en IA.
